# P14 交付说明

版本：`2026-06-21-p14-sync-architecture-cleanup`

## 目标

本版不是继续打小补丁，而是把 P10-P13 已验证正确的同步方向收紧成更硬的架构边界：

- 刷词中只写本地 cursor / activity draft，不追着每张卡 PATCH。
- `study_queued` 是学习中待同步，不是绿色成功，也不是红色错误。
- `cloud_ok` 是唯一绿色云端保存态，必须来自 verified push。
- `cloud_loaded` 只表示从云端加载，不再通过状态计算显示绿色。
- active-study guard、状态计算、同步决策诊断拆成独立模块。
- 加入最小 Node 测试，防止 cursor/hash/status 规则回退。

## 主要改动

### 1. 状态计算独立

新增：

- `assets/js/25a-sync-status-core.js`

`computeSyncStatus()` 迁出原 `25-sync-status-config.js`，配置校验仍保留在 25 文件。新的状态规则更硬：

- pending progress/activity 优先显示 `study_queued`。
- `cloud_ok` 必须满足：无 pending、无 dirty、localHash=baseRemoteHash、有 verified push 时间、有新鲜 remote confirmation、无 blocking error。
- `cloud_loaded` 不会被状态计算误显示为绿色。

### 2. active-study guard 独立

新增：

- `assets/js/27a-sync-active-study-guard.js`

集中维护：

- `getActiveStudyFacts()`
- `shouldDeferForActiveStudy()`
- `shouldAbortAutoPatchForActiveStudy()`
- `activeStudyDelayRemainingMs()`

自动学习、朗读、计时器、pointer、transition、idle window 都统一进入 active study 判断。

### 3. 同步决策诊断独立

新增：

- `assets/js/27b-sync-decision.js`

新增 `decideSyncAction()`，输出结构化决策：

- `BOTH_EMPTY_NOOP`
- `LOCAL_EMPTY_REMOTE_NONEMPTY_PULL`
- `LOCAL_NONEMPTY_REMOTE_EMPTY_PUSH`
- `LOCAL_DIRTY_REMOTE_SAME_PUSH`
- `LOCAL_CLEAN_REMOTE_CHANGED_PULL`
- `BOTH_CHANGED_MERGE_PUSH`
- `READ_ONLY_DIRTY`
- `REMOTE_INVALID`

现有 `syncTick()` 仍执行主流程，但会记录结构化 `sync:decision`，后续诊断更直接。

### 4. progress cloud write guard

`saveProgress()` / `saveUnknownProgress()` 增加硬保护：

- flash 学习中禁止直接写 cloud progress。
- 如果有旧路径误调用，会被转成 cursor 写入，并记录 audit：
  - `progress:cloud_write_blocked_in_flash`
  - `unknown_progress:cloud_write_blocked_in_flash`
- `flushProgressForCloud()` 是 cursor → cloud progress 的允许入口。

### 5. cloud_ok 语义收紧

- `markHashCleanFromRemote()` 内部主状态改为 `cloud_ok`。
- `cloud_saved` 只作为旧别名输入兼容。
- `finalizeVerifiedPatch()` 增加 `canMarkCloudOkAfterVerify()`，pending cursor/draft 存在时不允许 mark clean。

### 6. active-study 调度修复

- 去掉多个固定 `scheduleActiveStudyUpload(3000)`。
- 改为按剩余 idle window 自动计算，避免把 8 秒停手窗口缩短。

### 7. rescue 增强

`assets/rescue/rescue.js` 增加：

- backup score 排序。
- summary 显示 progress pending / activity draft pending。
- candidate 表显示 score / unitStats。

### 8. 最小测试

新增：

- `tests/p14_sync_core_test.js`
- `tests/p14_loader_smoke_test.js`

覆盖：

- cursor 保存不改变 business hash。
- flush 后 business hash 改变。
- pending 状态显示 `study_queued`。
- pull 成功只显示 `cloud_loaded`，不绿。
- verified push clean 才显示 `cloud_ok`。
- pending 会覆盖旧 `cloud_ok`。
- 本地非空 + 云端空的 decision 是 push local，不 pull。

## 真机验收重点

1. 刷词中：`study_queued` / 待同步 / 紫色。
2. 停手、暂停、离开 flash 后：flush → PATCH → verify → `cloud_ok`。
3. 初始化 pull：`cloud_loaded`，不能显示绿色云端保存。
4. 错 PAT / 只读：不能绿，dirty/read_only 保留本地。
5. 手机和平板互相同步时，重难点、已删、进度、activity 都不应丢。
